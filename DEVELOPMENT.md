# Compass — карьерный навигатор

Решение кейса 2 **Impact EdTech Hackathon**: продукт, который помогает школьнику
9–11 класса пройти путь «интересы → профессия → специальность → навыки →
университет → карьерная траектория».

Профиль ученика — это **рельеф**, а не строчка результата: интересы задают
высоты, специальности лежат на местности точками с координатами, план действий —
маршрут между ними.

## Как устроена рекомендация

Ранжирование **детерминированное**, а не сгенерированное. Модель извлекает
признаки и затем озвучивает уже посчитанный результат, но не выставляет баллы:

1. **Извлечение** — LLM разбирает интервью, увлечения и рассказ о себе в векторы
2. **Расчёт** — косинус RIASEC + веса ценностей + предметы + навыки → балл и построчная доказательная база
3. **Объяснение** — LLM превращает посчитанные числа в текст

Поэтому любую рекомендацию можно развернуть и оспорить: видно, из чего сложился
каждый балл и сколько процентов внесло каждое измерение.

Психологическая основа — валидированные модели, а не выдуманные вопросы:
**RIASEC (коды Холланда)** для интересов и **базовые ценности Шварца** для
воронки приоритизации.

## Запуск

```bash
cd app
npm install
cp .env.example .env.local   # вписать OPENAI_API_KEY и AUTH_SECRET
npx prisma generate && npx prisma db push
npm run db:seed
npm run dev
```

Открыть http://localhost:3000

## Стек

Next.js 15 · Prisma + SQLite · NextAuth v5 · Vercel AI SDK (OpenAI) · Tailwind v4 · Framer Motion

## Заметки по окружению

- Шрифты **самохостятся** в `public/fonts` — `next/font/google` намеренно не используется
- Скрипты `dev` и `start` запускают Node с `--use-system-ca`

Обе меры — из-за того, что на машине разработки антивирус перехватывает TLS, и
загрузка с `fonts.googleapis.com` молча падает.

## Структура

| Путь | Что внутри |
|---|---|
| `app/src/lib/career/` | движок: каталог специальностей, матчинг, роадмап, сборка контекста для LLM |
| `app/src/app/api/career/` | интервью, разбор увлечений, рекомендации, профиль |
| `app/src/components/compass/` | фирменные элементы: рельеф, шкала, роза, выноски |
| `app/src/components/navigator/` | шаги сбора профиля |
| `materials/` | визуальные референсы и описание кейса |
| `PITCH.md` | сценарий защиты |
